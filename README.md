## The entry

> The printer only jams when a deadline is five minutes away. I'm starting to think it's in middle management.

108 characters, one line. A setup anyone who has worked in an office recognises
(the printer jamming right before a deadline) with a surprise payoff (the printer
is in middle management).

## How it works

`main.py` writes the joke to `/output/entry.txt`, after a self-check that the text
is 1–200 characters, not only whitespace, and a single line — the competition's
gate requirements.

```sh
python3 main.py   # writes /output/entry.txt
```
